Из корневой папки проекта в терминале прописать :  
docker compose up --build

Для првоерки API удобная веб-страница :  
http://localhost:5029/swagger

Для того что бы открыть сам сайт :  
http://localhost:4200

Для остановки проекта прописать :  
docker compose down

При первом запуске все миграции применятся автоматически

Для проверки основной логики:  
dotnet test TestTask.slnx

Тесты проверяют CsvImportService, для этого используется SQLite база данных.Она создается в ОЗУ и таким образом она не меняет рабочую и не требует Docker.
Что соответвуюет быстроте проверке, для остальных сервесов не написаны Unit тесты, они слишком маленькие на мое мнение, основная логика находится в данном сервисе.
