Из корневой папки проекта в терминале прописать :
docker compose up --build
Для првоерки API удобная веб-страница :
http://localhost:5029/swagger
Для того что бы открыть сам сайт :
http://localhost:4200

При первом запуске все миграции применятся автоматически 

Для остановки проекта прописать :
docker compose down
